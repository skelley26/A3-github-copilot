What did you ask Copilot to help you build? How did you break down the problem?
First prompt was to make the page look more polished with bootstrap and css.
    1. I want to set up a basic html website that uses bootstrap functionalities. I want there to be a navigation bar at the top and an empty area where future posts will go.
    2. I also want to add a css to make the page look more interesting. I want to switch the navigation bar to be at the left side of the page, and it stays there even as you scroll the page.
Then, the next couple prompts were about customizing the navigation bar.
    1. can you make the navigation bar options appear in a list, with the categories Home, Account, Following, For you, and Log Out
    2. can you make the navigation list on the left be a vertical list instead of a horizontal list?
I noticed, on the home page, there was an area for creating a post that wasn't able to be interacted with yet, so I asked it to create a functionality when clicking on the + button.
    1. I also want to add a functionality to the "your first post starts here" green + button where you can actually draft a post and post it to the site
Lastly, I wanted to have the buttons on the navigation bar lead to other html pages, so I had it set that up.
    1. I've created html pages that, I want to link to the buttons on the navigation bar. I want the Account button to lead to account.html that asks the user if they want to create an account, following button to lead to an empty list, and the for you button to lead to an empty feed.
